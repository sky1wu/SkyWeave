# SkyWeave 日历与规划操作

## 行程日历

行程设置中的开始日期、结束日期和天数联动，天数包含首尾日期。支持 1–366 天，保存后自动生成对应数量的日期，无需逐日添加。未填写日期的 API 新建请求默认使用行程时区的当天，创建一日行程。

日期标签支持整天拖动，以及 Alt + 左右方向键排序。移动后按新位置显示“第 x 天”，并从行程开始日期重新分配日期。当天开始时间、事项、独立交通、评论及账单的关联保持不变。

缩短行程只允许移除末尾的空日期；只要超出范围的日期还有事项或账单，就返回 409，并保留未提交的日期设置，要求用户先整理。当天设置仅维护开始时间，不再提供名称、日期或删除操作。

升级时补齐原有日期范围中缺少的天数，并规范编号。如果原有天数超出旧日期范围，则延长结束日期以保留已有内容；不删除旧 Day 或其事项。

## 排序与路线

“全部折叠”将事项缩为一行名称，同时隐藏事项详情、关联账单与中间路线，保留整卡拖动及键盘排序。再次展开恢复详情和之前展开的路线状态。

路线顶部显示“展开路线／收起路线”，展开区域底部也提供收起入口。界面移除重新计算按钮；操作稳定 500ms 后自动计算发生变化的日期，包括跨日移动的两侧及当前未打开的日期。

## 选择控件

分类下拉每次打开都列出全部选项，支持搜索和自定义值。城市改为可搜索下拉，提供常用城市，并允许使用搜索框填写其他城市名称。下拉框支持方向键、回车选择和 Escape 关闭；在编辑弹窗内按 Escape 只关闭当前下拉框。

## API

- `PATCH /api/trips/:id`：以 `startDate`、`endDate` 维护日历，携带行程 `expectedVersion`。
- `POST /api/trips/:id/days/reorder`：`{ expectedVersion, dayIds }`，完整提交所有 Day ID；检查归属、重复、并发版本。
- `PATCH /api/days/:id`：只支持 `startMinutes` 和 `expectedVersion`。
- 原单独新增、删除 Day 接口返回 405，提示通过行程设置调整范围。

数据仍使用稳定的 Day ID；只有位置、生成名称和日期变化。高德配置变量及原 SQLite 数据卷路径保持原名，产品名与应用镜像使用 SkyWeave。

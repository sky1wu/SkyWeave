# SkyWeave 设计系统：城市漫游手册

## 设计方向

为一起旅行的人提供一本可以共同编辑的城市漫游手册。以城市线路的转折、站点和行程票夹为视觉语言；地图负责地理信息，时间线负责每天的先后安排，费用页负责清楚地对账。

### 核心色板

| 名称   | 色值      | 用途                           |
| ------ | --------- | ------------------------------ |
| 云白   | `#F5F8FC` | 应用背景与地图外围，保持通透感 |
| 纯白   | `#FFFFFF` | 编辑表单、内容与浮动面板       |
| 晴空蓝 | `#0762DF` | 品牌、主要操作、选中路线与导航 |
| 亮青   | `#17AEC4` | 分类图表与插画的辅助色         |
| 日光黄 | `#FFD452` | 路线终点和小面积重点信息       |
| 深海墨 | `#18324B` | 正文与标题，保证阅读对比度     |

辅助文字使用 `#5D7186`，选中浅底使用 `#E5F1FF`，边框使用 `#DBE5F0`。色彩以纯白和晴空蓝建立主次，亮青与日光黄保持少量出现。

错误、固定时间迟到等状态使用独立的可读语义色，并同时显示文字或图标。

### 字体与尺度

Manrope 用于拉丁字母与数字，中文使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC。品牌与页面大标题使用 650–750 字重；界面正文 14–15px，辅助信息 12–13px。金额与时间使用等宽数字。标题 28–40px，登录介绍标题可达 56px；移动端表单输入 16px。

### 布局方案比较

方案 A：顶栏横向标签。熟悉，但把品牌、行程身份和功能导航挤在一起，地图上方占用两条横栏。

```text
[品牌 / 行程名称 / 成员]
[行程 / 费用 / 成员 / 动态]
[每日安排 | 地图 | 地点池]
```

采用方案 B：桌面侧边导航与行程票夹。行程身份位于顶部，固定的左侧导航区分规划、查看、费用、成员和动态，地图与两个独立面板占据规划页其余空间。手机恢复水平导航，保留地点池与行程同时展开的拖动能力。文字左对齐，数值在表格内右对齐。

```text
[品牌         行程名称、日期              同行成员]
[行程] [每日安排]        地图        [地点池]
[费用] [时间 / 事项]                 [搜索]
[成员] [交通连接]                    [待安排地点]
[动态]
```

行程首页使用可搜索的双列行程票夹，去掉没有顺序语义的序号。登录页使用原创路线示意插画表达旅行规划；示意插画不承担真实地理或行程数据的职责。费用页把总支出、分类分布、个人余额、转账和明细划分为清楚的阅读区。

### 设计复核

最初的「旅行卡片网格」容易成为通用看板，因此只在首页采用票夹形态；规划页继续按时间连接事项，协作动态按事件排列，费用按账目组织。日光黄集中用于路线插画与总支出的小面积强调，不作为每个组件的装饰。没有无意义的编号、英文眉题或整页渐变。根据视觉反馈，原灰绿方案调整为晴空蓝、亮青与日光黄；降低底色灰度，增加主操作和信息重点的鲜明度。

## 组件与交互

沿用 shadcn/ui 的 Base UI 组件以及 dnd-kit，保留浮层焦点管理、键盘导航、删除确认与跨面板拖动。

- 主要按钮、表单控件约 40px；独立图标按钮提供明确名称与可见焦点。
- 8px 控件圆角、12px 内容表面、18px 浮动面板，按层级区分。
- 行程卡片显示真实日期、天数和成员，搜索没有结果时可以直接清空筛选。
- 桌面用 Dialog 编辑，手机用底部 Sheet；错误说明原因，空状态说明下一步。
- 每日标签、当前导航、地图模式具有明确的选中状态。
- 保留 250ms 手机长按拖动、普通触摸滚动、键盘排序、独立交通与手动路线的语义。
- 动效只用于交互反馈，并尊重 `prefers-reduced-motion`。
- 用户设置页沿用现有颜色与字体，桌面左侧显示账号身份，右侧以分隔线区分个人资料、修改密码和退出登录；手机改为单列。各表单独立显示保存结果，登录邮箱只读，首页和行程页均提供入口。
- 查看页沿用云白、纯白、晴空蓝、亮青、日光黄和深海墨，以及现有 Manrope / 中文字体。封面以真实行程名和日期建立身份，桌面左侧为日期目录，右侧按天连接事项；手机目录横向滚动、正文单列。日期与站点编号只表达真实顺序，路线装饰集中在封面，正文保留足够留白。
- 行程图沿用相同颜色与时间语义，将屏幕上的交互目录转换为连续的每日路线手册。Canvas 在浏览器内排版中文、跨行备注与跨日时间，输出 1200px 宽 PNG，无须截图地图或请求外部图片。内容过长时分图并标注续页，可单图下载或打包 ZIP；导出预览复用 Dialog / 手机 Sheet，支持范围选择、备注开关、错误重试与关闭后焦点恢复。

## 样式组织

- `src/app/globals.css`：语义颜色、字体、全局基础规则。
- `src/styles/layout.css`：规划、拖动、地图等已有结构规则。
- `src/styles/skyweave.css`：城市漫游手册主题与各页面的响应式布局。
- `src/styles/settings.css`：用户设置页与账号入口的响应式布局。
- `src/styles/itinerary.css`：行程查看页与导出预览的响应式布局。
- `src/domain/itinerary.ts`：查看页和行程图共用的阅读数据，复用规划时间算法。
- `src/lib/itinerary-poster.ts`：文字换行、图片分页与 PNG / ZIP 导出。
- `src/components/journey-art.tsx`：原创路线示意插画。
- `src/components/ui/`：基础控件，使用统一语义 token。

样式在 `components` 层，组件工具类保留明确覆盖能力。实际地图路线颜色与主题同步，地点分类颜色继续表达分类含义。

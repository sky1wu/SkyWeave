# 地图地点与独立交通

## 地图

地图展示当前日期的行程地点，以及整个行程中尚未安排的地点池记录。已在其他日期安排的地点不作为未安排地点重复展示。未填写坐标的地点仍保留在地点池，可补充定位后显示。

地点名称常驻，靠近时在附近错开，并用细线连接原位置。常用分类使用不同图标与颜色；自定义分类以分类首字作为标记。行程地点带顺序编号，未安排地点使用空心标记。点击未安排地点展开地点池并定位相应卡片，仍可拖动或点击加入某一天。

## 火车、飞机等独立交通

每天标题旁的“交通”可添加火车、飞机、长途汽车、轮船或其他交通。独立交通属于一个行程事项，有自己的起点和终点，不向高德查询其内部路线。

- 起终点可只填写城市或名称；也可从地点池选择、搜索具体车站或机场，或补充坐标。
- 状态为“暂定”或“已确认”，班次、出发时间、到达时间和预计用时均可后补。
- 有定位时，高德只计算上一地点至出发点、到达点至下一地点的接驳。内部交通以紫色虚线示意，不代表真实航路或铁路轨迹。
- 没有到达时间或用时时，下游时间保持不确定；不能将未知交通时间当作零。
- 如果接驳到达时已经超过班次出发时间，提示预计赶不上，后续时间转为不确定。接驳未知而班次时间已填写时，明确标注后续按填写时间暂估。
- 时间使用 Trip 时区，以所属 Day 的零点为基准；跨午夜选择“次日”。到达时间优先于估计用时。
- 支持复制、排序、跨日移动、评论和费用关联。端点选自地点池时计入安排次数；移除地点池来源保留独立交通中的起终点快照。

## 数据与 API

`day_items.transport` 为可空 JSON，旧事项保持 `null`。新增与编辑仍使用 `POST /api/days/:id/items` 和 `PATCH /api/items/:id`，编辑需携带 `expectedVersion`。

```json
{
  "title": "待定航班",
  "type": "transport",
  "transport": {
    "mode": "flight",
    "status": "tentative",
    "serviceNumber": null,
    "origin": { "name": "深圳" },
    "destination": { "name": "北京" },
    "durationMinutes": null
  }
}
```

端点还支持可空的 `sourcePlaceId`、`lat`、`lng`、`amapPoiId`、`address`。坐标必须成对填写，来源地点必须属于当前 Trip。`startMinutes`、`endMinutes` 仍在事项顶层；不提供时间即可保存暂定交通。

不包含订票、实时班次查询或出票状态同步；“已确认”由用户手动维护。
